# 💣 Minesweeper – JavaFX Desktop Game  

This is a fully custom **Minesweeper game** built from scratch using **Java, JavaFX, and FXML files**.  

The project uses **FXML layouts** for the UI, Java controller classes for game logic, and object-oriented principles to manage the board state, mines, and gameplay flow.  

## Features  
**Interactive Grid** – Reveal cells & place flags  
**Dynamic Game Logic** – Tracks mine locations and win/loss conditions  
**FXML-based UI** – Separates layout from logic for clean architecture  
**Event Handling** – Click detection for left/right actions  
**Restartable Gameplay** – Reset the board without restarting the app  

## Tech Stack  
- **JavaFX** for GUI & styling  
- **FXML** for declarative UI layout  
- **Java OOP** for game logic & controller classes  
- Developed in **Eclipse IDE**  

## How to Run  
1. Clone this repo  
2. Open the project in **Eclipse IDE** (or any JavaFX-supported IDE)  
3. Ensure JavaFX libraries are properly linked  
4. Run the `Main.java` file  

## Context  
This project was created as part of an **I311 Software Development** course at Indiana University.  
It demonstrates:  
- **Object-Oriented Design** for managing game state  
- **FXML + Controller patterns** for JavaFX applications  
- **Event-driven programming** in a desktop UI environment
