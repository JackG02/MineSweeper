# 💣 Minesweeper – Java Desktop Game  

This is a **Java implementation of Minesweeper**, a classic puzzle game where players clear a grid without detonating hidden mines.  

## Features  
Interactive grid-based gameplay  
Left-click to reveal cells  
Right-click to place flags  
Win/loss detection  
Adjustable grid sizes & mine counts  

## Tech Stack  
- **Java** (Swing for GUI)  
- **Object-Oriented Programming** principles
